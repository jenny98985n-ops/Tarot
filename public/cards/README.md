# TarotSage 塔羅牌面圖片資料夾 (Custom Card Faces Directory)

歡迎使用 TarotSage 自訂牌面圖片資料夾！
您可以將自己喜愛的塔羅牌牌面圖片（如經典偉特、新藝術塔羅、私人收藏或實體牌掃描圖）放入此資料夾中，系統將自動讀取並套用於全站抽牌儀式、牌陣解析、78張牌典與研習筆記中。

## 💡 更新方式

1. **直接放置檔案**：將依照上方名稱命名的圖片放入本資料夾 `/public/cards/`。
2. **透過網站介面更新**：在網站點擊 **「自訂牌面」** 按鈕，支援：
   - 單張牌點擊更換照片或輸入圖片網址
   - 批次選取多張圖片自動比對牌名匯入
   - 一鍵預覽與還原預設牌面
